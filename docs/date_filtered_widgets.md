LEGEND
- route fn = webapp/routes/<file>:<line of def>. Template paths are under webapp/templates/. Feeder prefixes: `r/` = webapp/routes/, `db/` = database/.
- tag:
  - `windowed` = `{{ scope_tag() }}`, which renders `<span class="scope-tag">LABEL</span>` where LABEL is the page scope label (e.g. "2026 Cycle", "All time", "Custom range").
  - `All time` or fixed text = `scope_tag('...')`, which renders `scope-tag scope-tag-fixed`.
  - `none` = widget has no tag.
- axis = the axis passed to `resolve_time_scope` (what the bar says). `(eff: X)` means the SQL actually windows on a different date.
- window cell values: yes / no / partial. `NO` in capitals marks a tagged-windowed widget whose query ignores the window (listed in section C).
- Test files:
  - SR = tests/test_scope_rollout.py
  - PS = tests/test_profile_scope.py
  - WA = tests/test_webapp.py::TestWebApp
  - AF = tests/test_analytics_features.py
  - AD = tests/test_analytics_date_semantics.py
  - FF = tests/test_federal_fec.py
  - EV = tests/test_experimental_viz_lab.py
  - LR = tests/test_lobbying_routes.py
- Test markers:
  - [iw] = asserts content with only in-window fixture rows, so it would not catch a dropped window.
  - [at] = asserts the all-time or unbounded branch only.
  - [fl] = calls the feeder function directly, not the rendered page.
  - Unmarked = rows inside and outside the window, or output compared across scopes.
- NONE = no test asserts windowed content for this widget.
